NecxaWA is a real console for the OpenWA WhatsApp API gateway. Run the backend on your own machine or server with Docker, pair your WhatsApp with a QR code, and send messages, media and webhooks through a genuine REST API — no fake simulations.

Launch Console Self-host in 5 minutes

What you actually get

Everything below talks to a real OpenWA backend over its documented REST API. Nothing is simulated.

Real session pairing

Create a WhatsApp session and pair it by scanning a live QR code served by the backend — or use an 8-digit pairing code. Same flow as WhatsApp Web.

Real message sending

Send text, images, documents, audio, video, stickers, locations, polls and contacts through real POST /messages/send-* endpoints.

Chats & contacts

List real chats from the paired account, check whether a number is on WhatsApp, and read message history per chat.

Webhooks

Register real webhook URLs per session and receive live events for inbound messages, status changes and delivery updates.

API-key security

Every request is authenticated with an X-API-Key header. Keys are created and revoked from the backend; the console never hardcodes secrets.

100% free software

OpenWA is MIT-licensed and this console is static — host it on GitHub Pages for free, run the backend on your own hardware with Docker.

Go live in 5 minutes

The console on this page is a static frontend. The real engine is OpenWA, which you run yourself — free, on your own machine or any server.

01

Run the OpenWA backend

Docker only. The API starts on port 2785.

git clone https://github.com/rmyndharis/OpenWA cd OpenWA docker compose up -d
02

Copy your API key

On first boot OpenWA prints a random admin key. Grab it from the logs.

docker logs openwa-api 2>&1 | grep -i "api key"
03

Connect this console

Open the console, paste http://localhost:2785 and your API key, hit Test — then create a session and scan the QR.

Console → Connection → Test connection

Want it online 24/7?

Run the same docker compose up -d on any always-on machine — a home server, or a free-tier VPS such as Oracle Cloud's Always Free VM. Then point this console at https://your-server:2785 (put a reverse proxy with TLS in front, and set CORS_ORIGINS to this site's URL). The console itself stays free on GitHub Pages forever.

Fair warning: this automates WhatsApp Web, which is unofficial. WhatsApp may restrict numbers that send bulk or spammy traffic. Use your own number, warm it up gradually, and only message people who expect your messages.
