API Documentation

Every endpoint with working code samples in five languages. Replace YOUR_API_KEY and {sessionId} with your values.

Authentication

All requests must carry your API key in the x-api-key header. Generate keys from the dashboard — they can be scoped to specific sessions or chats.

auth header
# Every request includes this header
x-api-key: nwa_live_9f3kQ7xLm2Zp...

Base URL

Self-hosted instances serve the API on port 3000 by default.

http://localhost:3000/api

POST Create session

/api/sessions

Creates a new WhatsApp session. Scan the returned QR code with WhatsApp on your phone to pair it.

FieldTypeDescription
namestringHuman-readable session name required
create session
curl -X POST http://localhost:3000/api/sessions \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "sales-inbox"}'
const res = await fetch('http://localhost:3000/api/sessions', {
  method: 'POST',
  headers: { 'x-api-key': API_KEY, 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'sales-inbox' })
});
const { sessionId, qr } = await res.json();
import requests
r = requests.post(
  "http://localhost:3000/api/sessions",
  headers={"x-api-key": API_KEY},
  json={"name": "sales-inbox"},
)
session_id, qr = r.json()["sessionId"], r.json()["qr"]
$ch = curl_init("http://localhost:3000/api/sessions");
curl_setopt($ch, CURLOPT_HTTPHEADER, ["x-api-key: $apiKey", "Content-Type: application/json"]);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode(['name' => 'sales-inbox']));
body, _ := json.Marshal(map[string]string{"name": "sales-inbox"})
req, _ := http.NewRequest("POST", base+"/api/sessions", bytes.NewBuffer(body))
req.Header.Set("x-api-key", apiKey)

POST Create automation rule

/api/sessions/{sessionId}/automation-rules

Creates a keyword-based auto-reply rule. When an incoming message matches, the reply is sent instantly.

automation rule
curl -X POST http://localhost:3000/api/sessions/{sessionId}/automation-rules \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"trigger": "pricing", "match": "contains", "reply": "Our plans start at Rs.999/month. Details: necxawa.com"}'
await fetch(`http://localhost:3000/api/sessions/${sid}/automation-rules`, {
  method: 'POST',
  headers: { 'x-api-key': API_KEY, 'Content-Type': 'application/json' },
  body: JSON.stringify({ trigger: 'pricing', match: 'contains', reply: 'Our plans start at Rs.999/month.' })
});
requests.post(
  f"http://localhost:3000/api/sessions/{sid}/automation-rules",
  headers={"x-api-key": API_KEY},
  json={"trigger": "pricing", "match": "contains",
        "reply": "Our plans start at Rs.999/month."},
)
$ch = curl_init("http://localhost:3000/api/sessions/$sid/automation-rules");
curl_setopt($ch, CURLOPT_HTTPHEADER, ["x-api-key: $apiKey", "Content-Type: application/json"]);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
  'trigger' => 'pricing', 'match' => 'contains', 'reply' => 'Our plans start at Rs.999/month.']));
payload, _ := json.Marshal(map[string]string{
  "trigger": "pricing", "match": "contains", "reply": "Our plans start at Rs.999/month."})
req, _ := http.NewRequest("POST", base+"/api/sessions/"+sid+"/automation-rules",
  bytes.NewBuffer(payload))

Webhooks

Register a webhook URL to receive real-time events — incoming messages, delivery receipts, session status changes. Events arrive as JSON POST requests.

webhook payload — message.received
{
  "event": "message.received",
  "sessionId": "sales-inbox",
  "timestamp": "2026-09-23T10:30:00Z",
  "data": {
    "from": "919876543210",
    "type": "text",
    "body": "Hi, I want pricing details"
  }
}

Example receiver in Node.js:

webhook receiver — node
import express from 'express';
const app = express(); app.use(express.json());

app.post('/wa-webhook', async (req, res) => {
  const { event, data } = req.body;
  if (event === 'message.received') {
    console.log(`New message from ${data.from}: ${data.body}`);
    // ...your bot logic here, then reply via send-text API
  }
  res.sendStatus(200);
});
app.listen(4000);
