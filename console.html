Apna khud ka backend (optional)

How it works

Ye console tumhare private relay channel ke through backend se judta hai. WhatsApp connect karne ke liye apna khud ka backend chalao — 1-click codespace: yahan tap karke codespace banao, 2-3 min ruko (backend khud chal padega), phir uska public URL + API key upar direct backend me daalo. Uske baad Sessions me QR aayega — scan karte hi WhatsApp connected.

Sessions

Each session is one WhatsApp account. Create one, then pair it via QR — exactly like linking WhatsApp Web.

Send message

Sends through the real POST /api/sessions/{id}/messages/send-* endpoints of the selected session.

Chats

Real chat list from the selected session (GET /api/sessions/{id}/chats).

Webhooks

Register a URL to receive live events (messages, status) from the selected session. Event filter * subscribes to everything.

Number check

Check whether a phone number is registered on WhatsApp (GET /contacts/check/{number}).

Console log

Every API call this console makes is logged here for debugging.

AI Auto-Reply

Jab tum offline ya busy ho, AI tumhare WhatsApp messages ka jawab khud dega — jis language me message aayega, usi me jawab. Neeche ON karo aur apni Gemini API key dalo (free, 2 min me banti hai).

Kaise kaam karta hai

1. Gemini API key banao (upar link) aur yahan paste karke Save dabao.
2. Auto-reply ON karo jab tum busy/offline ho.
3. Koi message aayega to AI 15-20 sec ruk ke (natural lage) usi language me jawab bhej dega.
4. Wapas aake OFF kar do — ya ON hi rehne do.

Key sirf tumhare browser aur tumhare codespace me rehti hai — kahin aur nahi jaati.
