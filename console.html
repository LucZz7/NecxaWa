How it works

Ye console tumhare private relay channel ke through backend se judta hai. Tumhara WhatsApp session backend pe chalega — QR scan ke baad session yahin se manage hoga: messages bhejo, chats dekho, sab kuch.

Sessions

Each session is one WhatsApp account. Create one, then pair it via QR — exactly like linking WhatsApp Web.

Send message

Sends through the real POST /api/sessions/{id}/messages/send-* endpoints of the selected session.

Chats

Real chat list from the selected session (GET /api/sessions/{id}/chats).

Webhooks

Register a URL to receive live events (messages, status) from the selected session. Event filter * subscribes to everything.

Number check

Check whether a phone number is registered on WhatsApp (GET /contacts/check/{number}).
