1-Click Cloud Backend Step-by-step guide

Backend connection

Point this console at your OpenWA backend. Everything is stored only in this browser — nothing leaves your machine except API calls to your own server.

How to get these values

On the machine running OpenWA:

# 1. start the backend (from the OpenWA repo)
docker compose up -d

# 2. copy the first-boot admin API key
docker logs openwa-api 2>&1 | grep -i "api key"

# 3. backend URL is http://<that-machine>:2785

Sessions

Each session is one WhatsApp account. Create one, then pair it via QR — exactly like linking WhatsApp Web.

Send message

Sends through the real POST /api/sessions/{id}/messages/send-* endpoints of the selected session.

Chats

Real chat list from the selected session (GET /api/sessions/{id}/chats).

Webhooks

Register a URL to receive live events (messages, status) from the selected session. Event filter * subscribes to everything.

Number check

Check whether a phone number is registered on WhatsApp (GET /contacts/check/{number}).

Console log

Every API call this console makes is logged here for debugging.
